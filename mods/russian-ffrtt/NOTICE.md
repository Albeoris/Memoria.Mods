# FFRTT Russian localization, version 3.20

Russian translation by FFRTT (FF Russian Translation Team).

Русская локализация — FFRTT.

The player package contains the translation and edition-specific text overrides. It uses the installed English resources for native text bindings.

The Russian subtitle track is part of this translation package. Its opening movie component uses the approved companion video and camera.
